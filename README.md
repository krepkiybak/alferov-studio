# ALFEROV ART STUDIO: печать и вышивка на одежде

[Сайт для покупателей](https://krepkiybak.github.io/alferov-studio/) · [Репозиторий GitHub](https://github.com/krepkiybak/alferov-studio)

Одностраничный каталог мастерской Игоря. Чистые HTML, CSS и JavaScript, без сборки и сторонних библиотек. Фотографии и шрифты находятся в репозитории: сайт не зависит от внешних CDN.

## Возможности

- Три футболки с фотографиями заказчика, общий вид и увеличение принта.
- Карточка товара, полноэкранное фото, выбор размера S-XXL и количества с пересчётом итоговой суммы.
- Форма с автоматическим форматированием телефона (`+7 999 123 45 67`), Telegram и необязательным комментарием.
- Проверка полей, формирование заявки с моделью, цветом, размером, количеством, ценой за штуку и итоговой суммой.
- Переход в чат **@ig_alferov** с готовым сообщением; запасное копирование текста.
- Блоки о печати, вышивке, оптовых заказах и об Игоре.
- Адаптивная вёрстка, клавиатурная навигация, системные диалоговые окна.
- Интерактивная схема форматов A7, A6, A5, A4, A3 и A3+: грудь или спина, вертикальная или горизонтальная ориентация и выбор одного из четырёх способов нанесения.
- Свободное перемещение и изменение размера области в контуре футболки, числовая настройка с шагом 1 мм и три формы для примерки. Ограничение A3+ действует в обоих поворотах; для круга максимальный диаметр составляет 32,9 см.
- Форма своей идеи с вопросами об одежде, количестве, макете, сроках и контактах. Выбранные параметры примерки подставляются в запрос.
- Предпросмотр готового запроса, редактирование ответов и отправка через Telegram с запасной кнопкой копирования. Контакты очищаются при закрытии формы.
- Короткие русские слова и единицы измерения связаны неразрывными пробелами, включая динамические тексты.

## Схема нанесения

Визуализация использует условную футболку с шириной полочки 54 см и длиной 74 см. Это схема для сравнения, а не замеры товара. Области нанесения масштабируются одинаково, по 6 единиц SVG на сантиметр. A3+ принят равным 329 × 483 мм; фактический размер зависит от оборудования.

Размеры сверены с [руководством Epson](https://support.epson-europe.com/onlineguides/en/spr1800/ref_g/spec_2.htm). Прямая печать и DTG показаны как одна технология, см. [описание Brother](https://help.brother-usa.com/app/answers/detail/a_id/160505/p/7549). Способ нанесения согласовывается по макету, ткани и тиражу.

Ближайший формат оценивается по разнице размеров сторон с учётом поворота, а не как обещание вместить макет в этот формат. В Telegram передаются фактические ширина и высота, ближайший формат, сторона футболки, смещение центра относительно середины и отступ верхней границы от верха футболки. Выбранная форма примерки в сообщение не добавляется. Проверка контура учитывает горловину и рукава; управление доступно мышью, касанием, стрелками и числовыми полями.

Формат A7 составляет 74 × 105 мм, см. [спецификацию Epson](https://files.support.epson.com/docid/cpd5/cpd56112/source/scanners/source/placing_originals/reference/ds70_ds80w_es50_es65wr/ds70_es65wr_document_spex_input.html).

Черновик документа по персональным данным готовится отдельно. До заполнения данных оператора и утверждения процессов он не публикуется как действующая политика. Папка `output/` исключена из Git и публикации сайта.

## Запуск

Нужен Node.js 20 или новее. Установка зависимостей не требуется.

```sh
node scripts/serve.mjs
```

Откройте http://127.0.0.1:4173. Запускайте через HTTP-сервер: ES-модули не работают при открытии HTML через `file://`.

Проверки:

```sh
npm run check
```

## Настройки

- `dist/catalog.js`: модели, цены, изображения, контакт и список размеров.
- `dist/index.html`: тексты страницы и формы.
- `dist/styles.css`: оформление и мобильная версия.
- `dist/order.js`: проверка контактов и текст заявки.

Для первой версии установлена рекомендованная цена **1 990 ₽** за каждую модель по ориентиру российского рынка. Это не расчёт себестоимости: владелец может изменить её в `catalog.js`. Набор размеров S-XXL предварительный. Состав ткани, замеры, сроки изготовления и доставки не выдуманы: их согласовывает менеджер.

## Как поступают заказы

Сайт **не принимает и не хранит заявки на сервере**. Он подготавливает сообщение для Telegram. Покупатель должен нажать кнопку перехода, а затем сам отправить сообщение в чате. До этого сайт не сообщает об успешной отправке. После отправки сообщения менеджер связывается с покупателем. Если клиент Telegram не подставил текст, его можно скопировать в раскрывающемся блоке.

Данные формы находятся только в памяти страницы, не записываются в LocalStorage, аналитику или Git. Закрытие карточки очищает контакты. Онлайн-оплаты нет. Автоматический приём заявок без Telegram потребует отдельного серверного подключения.

## Публикация

Готовый сайт: папка `dist`. Её можно разместить на любом статическом хостинге. `.openai/hosting.json` связывает проект с Sites.

Для GitHub Pages настроен `.github/workflows/pages.yml` и выбран источник **GitHub Actions**. При отправке коммита в `main` workflow проверяет проект и публикует `dist`; также доступен ручной запуск. Основной адрес: https://krepkiybak.github.io/alferov-studio/. При смене основного домена обновите `og:url`, `og:image` и canonical в HTML.

## Изображения и шрифт

Исходные изображения предоставлены владельцем проекта. Они оптимизированы в WebP без изменения содержимого. При необходимости подготовить их заново: `python scripts/prepare-assets.py <папка-с-оригиналами>` (нужен Pillow).

Golos Text используется по SIL Open Font License; лицензия включена в `dist/assets/OFL.txt`.

Учётные данные и токены не должны добавляться в исходники, URL Git remote или файлы проекта.
